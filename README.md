# SuperBooleans.js
Are you bored of the normal true or false? well, here we have a library to create booleans

[Inspired by Naruyoko OmegaNum]

```js
// you create booleans like this
var boolName = new bool(x) <--- x is a number like for example 0.9 (between 0 and 1)

if x is 0.9, that means there's a 90% chance of it being true and 10% chance of it being false
```
Functions: ```js
cmp, gte, gt, lt, lte, eq
```
